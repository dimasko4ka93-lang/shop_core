# E-commerce Homework

Проект интернет-магазина с использованием принципов ООП и инкапсуляции.

## Реализованные классы:
- `Product` — товар (name, description, price, quantity). 
  - Атрибут цены (`__price`) сделан приватным.
  - Реализованы геттер и сеттер с защитой от нулевых и отрицательных значений.
  - Добавлены магические методы: `__str__` (строковое отображение) и `__add__` (сложение стоимости товаров).
  - В `__add__` используется `type()`: складывать можно только объекты **строго одного класса**.
- `Category` — категория (name, description). 
  - Список товаров (`__products`) сделан приватным.
  - Реализован геттер `products` для вывода списка товаров в виде отформатированной строки.
  - Добавлен магический метод `__str__` для вывода общего количества товаров на складе.
  - Метод `add_product()` проверяет через `isinstance`, что добавляется `Product` или его наследник, иначе выбрасывает `TypeError`.

## Классы-наследники (ДЗ 16.1):
- `Smartphone(Product)` — смартфон. Дополнительные атрибуты: `efficiency`, `model`, `memory`, `color`.
- `LawnGrass(Product)` — трава газонная. Дополнительные атрибуты: `country`, `germination_period`, `color`.

## Новые возможности (ДЗ 16.1):
- **Ограничение сложения:** В `Product.__add__` добавлена проверка через `type()`. Попытка сложить товары разных классов (например, `Smartphone` и `LawnGrass`) выбрасывает `TypeError`.
- **Ограничение добавления:** В `Category.add_product` добавлена проверка через `isinstance()`. Попытка добавить в категорию объект, не являющийся `Product` или его наследником, выбрасывает `TypeError`.

## Новые возможности (ДЗ 14.2):
- **Инкапсуляция:** Приватные атрибуты `__price` и `__products` защищают данные от случайного изменения.
- **Добавление товаров:** Метод `add_product()` позволяет добавлять товар в категорию и увеличивает класс-атрибут `product_count`.
- **Класс-метод `new_product`:** Создает товар из словаря. 
  - *Дополнительное задание:* При передаче списка существующих товаров метод ищет дубликаты по имени, суммирует количество и выбирает наибольшую цену.
- **Вспомогательный модуль `utils.py`:** Реализована функция `load_categories_from_json` для загрузки категорий и продуктов из JSON-файла.


## Новые возможности (ДЗ 16.2):
- **Абстрактный класс `BaseProduct`:** Выделен базовый класс для всех продуктов.
- **Класс-миксин `InfoMixin`:** При создании продукта печатает информацию о классе и параметрах.
- **Иерархия:** `Product` наследуется от `InfoMixin` и `BaseProduct`.
- **`__repr__`:** Добавлен для удобного отображения списка продуктов.

## Новые возможности (ДЗ 17.1):
- **Обработка нулевого количества:** При создании `Product` с `quantity=0` выбрасывается `ValueError`.
- **Метод `middle_price()`:** Подсчитывает среднюю цену товаров в категории. Если товаров нет — возвращает `0`.
