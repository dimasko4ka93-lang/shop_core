# E-commerce Homework

Проект интернет-магазина с использованием принципов ООП и инкапсуляции.

## Реализованные классы:
- `Product` — товар (name, description, price, quantity). 
  - Атрибут цены (`__price`) сделан приватным.
  - Реализованы геттер и сеттер с защитой от нулевых и отрицательных значений.
  - Добавлены магические методы: `__str__` (строковое отображение) и `__add__` (сложение стоимости товаров).
- `Category` — категория (name, description). 
  - Список товаров (`__products`) сделан приватным.
  - Реализован геттер `products` для вывода списка товаров в виде отформатированной строки.
  - Добавлен магический метод `__str__` для вывода общего количества товаров на складе.

## Новые возможности (ДЗ 14.2):
- **Инкапсуляция:** Приватные атрибуты `__price` и `__products` защищают данные от случайного изменения.
- **Добавление товаров:** Метод `add_product()` позволяет добавлять товар в категорию и увеличивает класс-атрибут `product_count`.
- **Класс-метод `new_product`:** Создает товар из словаря. 
  - *Дополнительное задание:* При передаче списка существующих товаров метод ищет дубликаты по имени, суммирует количество и выбирает наибольшую цену.
- **Вспомогательный модуль `utils.py`:** Реализована функция `load_categories_from_json` для загрузки категорий и продуктов из JSON-файла.
