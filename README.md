# E-commerce Homework

Реализованы классы:
- `Product` — товар (name, description, price, quantity).
- `Category` — категория (name, description, products), а также атрибуты класса
  `category_count` и `product_count`, которые автоматически увеличиваются при создании объектов.

Добавлены тесты pytest на инициализацию и подсчёт сущностей.
