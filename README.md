# E-commerce Homework

Реализованы классы:
- `Product` — товар (name, description, price, quantity). Цена (`__price`) сделана приватной. Реализованы геттер и сеттер (с защитой от нулевых и отрицательных значений).
- `Category` — категория (name, description). Список товаров (`__products`) сделан приватным. Реализован геттер `products` для вывода списка товаров в виде строки.

## Новые возможности (ДЗ 14.2):
- **Инкапсуляция:** Приватные атрибуты `__price` и `__products` защищают данные от случайного изменения.
- **Добавление товаров:** Метод `add_product()` позволяет добавлять товар в категорию и увеличивает класс-атрибут `product_count`.
- **Класс-метод `new_product`:** Создает товар из словаря. 
  - *Дополнительное задание:* При передаче списка существующих товаров метод ищет дубликаты по имени, суммирует количество и выбирает наибольшую цену.
- **Тестирование:** Добавлены тесты pytest для проверки новой функциональности. Покрытие функционального кода (models.py) — 100%.

## Запуск
- Установка зависимостей: `poetry install`
- Запуск демо-скрипта: `poetry run python main.py`
- Запуск тестов: `poetry run python -m pytest`
